Política de Privacidade

Última atualização: 21 de outubro de 2026

O aplicativo brilhodavida é uma ferramenta de uso pessoal, usada somente pelo dono do canal Brilho da Vida no YouTube.

Quais dados são acessados

Com autorização do dono do canal, o aplicativo lê, pelas APIs do YouTube (YouTube Data API e YouTube Analytics API), apenas as estatísticas do próprio canal: visualizações, inscritos, curtidas, comentários e tempo assistido dos vídeos. O acesso é somente leitura.

Como os dados são usados e guardados

Os dados ficam armazenados apenas no computador do dono do canal, para acompanhar o desempenho dos vídeos. Nenhum dado é vendido, compartilhado ou enviado a terceiros, e o aplicativo não coleta dados de outras pessoas.

Serviços do Google

Este aplicativo usa os Serviços de API do YouTube. Ao usá-lo, aplicam-se os Termos de Serviço do YouTube e a Política de Privacidade do Google.

Como revogar o acesso

O acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions. Os dados guardados localmente podem ser apagados quando o dono desejar.
